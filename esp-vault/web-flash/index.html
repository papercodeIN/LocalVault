🔐 ESPVault

Install firmware on your ESP32, ESP32-C3, ESP8266 (D1 Mini), or Raspberry Pi Pico W directly from this page.

Web Serial not supported. Use Chrome, Edge, or Firefox on desktop/Android. This page must be served over HTTPS to use Web Serial.
Firmware version: 1.0.0 | Source code | Arduino IDE guide | PlatformIO guide

How it works

  1. Click "Connect Device & Install" and choose your device from the browser dialog
  2. The correct firmware for your board is automatically selected and flashed
  3. After flashing, the device creates a WiFi hotspot: LocalVault-XXXXXX
  4. Connect to that hotspot and open http://192.168.4.1
  5. Enter your home WiFi credentials, optionally set a static IP
  6. Device restarts, joins your network — open its IP in any browser to use LocalVault

Requirements

  • Chrome, Edge, or Firefox (desktop or Android) — not Safari/iOS (no Web Serial support)
  • This page must be served over HTTPS (or localhost)
  • A USB data cable (charge-only cables won't work)
  • For Pico W: hold BOOTSEL while plugging in, then release before clicking Install
